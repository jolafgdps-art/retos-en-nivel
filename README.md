# Retos en Nivel

Mod de Geode para Geometry Dash que muestra un reto aleatorio al entrar en un nivel.

## Datos del mod

- **ID:** jolaf.retosenivel
- **Versión:** 1.2.1
- **Desarrollador:** Jolaf
- **Geometry Dash:** Android 2.2081
- **Geode:** 5.10.1
- **Plataforma:** Android 64-bit

## Descarga

Descarga la versión 1.2.1 desde la [release v1.2.1](https://github.com/jolafgdps-art/retos-en-nivel/releases/tag/v1.2.1) o directamente desde [jolaf.retosenivel-1.2.1.geode](https://github.com/jolafgdps-art/retos-en-nivel/raw/v1.2.1/releases/jolaf.retosenivel-1.2.1.geode).

## Código fuente

El código fuente está disponible públicamente en [retos-en-nivel-geode](https://github.com/jolafgdps-art/retos-en-nivel-geode), incluyendo src/main.cpp, CMakeLists.txt y mod.json.

## Instalación

1. Descarga el archivo .geode.
2. Ábrelo con Geode o colócalo en la carpeta de mods de Geode.
3. Inicia Geometry Dash y entra a un nivel para ver el reto.

## Publicación en el índice oficial de Geode

El código fuente está disponible para revisión. Para solicitar la inclusión en el índice oficial de Geode, usa el enlace directo de descarga de arriba desde la cuenta del desarrollador en el índice.
