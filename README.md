# Retos en Nivel

Mod de Geode para Geometry Dash que muestra un reto aleatorio al entrar en un nivel.

## Datos del mod

- **ID incluido en el archivo:** retos.challenge.v2
- **Versión incluida en el archivo:** 1.2.0
- **Desarrollador:** Jolaf
- **Geometry Dash:** Android 2.2081
- **Geode:** 5.10.1
- **Plataforma:** Android 64-bit

## Descarga

[Descargar el archivo .geode](https://github.com/jolafgdps-art/retos-en-nivel/raw/main/releases/retos-en-nivel-android-2.2081-jolaf.geode)

Este archivo fue subido tal como fue recibido, sin modificar su contenido.

## Código fuente

El código fuente está disponible públicamente en [retos-en-nivel-geode](https://github.com/jolafgdps-art/retos-en-nivel-geode).

## Instalación

1. Descarga el archivo .geode.
2. Ábrelo con Geode o colócalo en la carpeta de mods de Geode.
3. Inicia Geometry Dash y entra a un nivel para ver el reto.
